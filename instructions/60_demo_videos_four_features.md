# 60: 4機能の解説動画を一括作成(レポート/ナレッジ/ベストプラクティス/タグ付き対象、字幕+イントロ/アウトロ付き)

## 背景

- 既存のデモ動画運用(demo/フォルダ、Playwright+ffmpeg)に倣い、以下4つの機能について解説動画を作成する
  1. レポート(日次/週次/月次サマリ)
  2. ナレッジ(Loop構造、承認フロー)
  3. ベストプラクティス診断(診断実行・結果一覧・ルールリファレンス)
  4. タグ付きClient/Device(タグ付与・一覧・詳細)
- 4本は別ファイルとして出力する(1本にまとめない)
- 字幕は既存運用に合わせて日本語・です/ます調で統一する
- イントロ/アウトロは`video-bumper`スキル(`~/claude/blog-video-bumper`のCLI、`npm run attach`/`npm run attach:inbox`)を使って付与する。非破壊で別名出力される(`--no-intro`/`--no-outro`フラグあり、今回は両方付ける通常運用)

## タスク

### Task 1: 4本分の録画

1. 4機能それぞれについて、既存のデモ動画作成運用(Playwright操作スクリプト、demo/フォルダの命名規則・バージョニング)に沿って録画する
   - 既存動画を上書きしない、既存の番号体系(work35, 36...等)の続きとして新規ファイルを採番する
   - 各機能の一連の操作(例: ベストプラクティスなら「診断実行→結果一覧→展開表示→ルールリファレンス」、タグ付き対象なら「タグ付与→一覧→Client詳細→Device詳細」)が伝わるシナリオにする
2. 各動画に日本語字幕(です・ます調)を生成する(既存の字幕生成フローに従う)

### Task 2: イントロ/アウトロの付与

1. `~/claude/blog-video-bumper`のCLI(`npm run attach`または`npm run attach:inbox`)を使い、Task 1で作成した4本の生録画それぞれにイントロ・アウトロを付与する
2. `config.json`のinboxDir/finalDirの既存設定に従う(録画ファイルをinboxDirに置いてattachする、またはattach:inboxで一括処理する、どちらか適切な方法で進めてよい)
3. 4本とも別ファイルとして最終出力する(1本の動画に4機能をまとめない)

### Task 3: 確認

1. 4本の最終動画それぞれについて、字幕が正しく表示されること・イントロ/アウトロが付いていることを確認する
2. 既存の動画ファイルを上書きしていないことを確認する
3. `.gitignore`の既存パターン(55番で修正済みのglob)で新規ファイルが適切に除外される(または意図的に含める)ことを確認する

## 制約

- 4本は必ず別ファイルにする
- 既存の動画・字幕ファイルは上書きしない(別バージョンとして保存)
- Central/Mistの設定変更は一切行わない
- git操作は行わない

## 完了報告

verified-report形式で報告すること。特に:

- 4本それぞれのファイルパス・所要時間・字幕の確認結果
- video-bumperによるイントロ/アウトロ付与の確認結果
- 既存ファイルへの影響が無いことの確認
