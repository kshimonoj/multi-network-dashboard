# 37: 36番デモ動画の「3倍速」バッジ表示を削除(再録画なしで対応)

## 背景

36番で作成した`demo/demo_02b_event_to_investigation_v2.mp4`の早送り区間に、右上に表示される「▶▶ 3倍速」のバッジ(`make-video36.mjs`が早送り区間に焼き込んでいるオーバーレイ)が不要なので削除したい。**Playwrightでの再録画は行わず、既存の生録画データを使って動画の再生成だけで対応できるか確認してから進めること。**

## タスク

### Task 1: 再録画が不要であることの確認

1. `demo/`配下(`demo/work36/`等)に、36番の録画時に生成された生の`.webm`(Playwrightで録画した136.7秒のソース)や、trim/setpts/concat前の中間ファイルが残っているか確認する
2. 残っていれば、`make-video36.mjs`(または同等のffmpeg処理スクリプト)を直接再実行するだけで、再録画せずに動画を作り直せる。この場合はTask 2に進む
3. 生録画データが残っていない場合は、再録画が必要になる旨と、再録画にあたって34・35・36番の環境がそのまま使えることを完了報告に明記し、ユーザーの指示を仰ぐこと(独断で再録画を実行しない)

### Task 2: 「3倍速」バッジの削除

1. `make-video36.mjs`内の、早送り区間に「▶▶ 3倍速」バッジを描画している箇所(drawtext等のフィルタ)を特定する
2. その描画処理だけを削除する(早送り自体(setpts等によるスピードアップ処理)は維持し、バッジ表示のみを取り除く)
3. 字幕(です・ます調)・早送り区間・その他の処理には手を加えない

### Task 3: 再生成・確認

1. 修正したスクリプトを実行し、動画を再生成する
2. 生成された動画からバッジが表示されていた時間帯のフレームを数枚抽出し、バッジが表示されていないことを目視確認する
3. 字幕・早送り箇所・全体の長さが36番と変わっていないことを確認する
4. `demo/`ディレクトリの既存ファイル(34番・35番の動画)に影響が無いことを確認する

## 完了報告

verified-report形式で簡潔に報告すること。特に:

- 生録画データが残っていて再録画不要だったか、それとも再録画が必要だったか
- バッジ削除後のフレーム確認結果
- 動画の長さ・ファイルサイズ・保存先パス(上書きか新規ファイルか)
- 34・35番の既存ファイルへの影響が無いことの確認

git操作は行わないこと。
