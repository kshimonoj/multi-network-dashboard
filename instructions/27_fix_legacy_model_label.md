# 27: モデル未記録の旧履歴("model=(旧・未指定)")の表示修正(multi-network-dashboard)

## 背景

自動調査等、一部の古い履歴レコードには`model`フィールドが記録されておらず、画面上「model=(旧・未指定)」と表示されている。この時点でのアプリの既定モデルはSonnetだったはずなので、実際にはSonnetで実行されていたと考えられる。

## タスク

1. `model`フィールドが記録されていない古い履歴レコードについて、実際にその時点でアプリが使っていた既定モデルがSonnetであったことをコード上(既定値の設定箇所)から確認する
2. 表示ロジック(Turn.tsx/Timeline.tsx等、モデル名を表示している箇所)を修正し、`model`が未設定の場合は「(旧・未指定)」ではなく「Sonnet(推定・旧履歴)」のように、実態が推測できる表示にする
3. `model`が実際に記録されているレコード(Sonnet/Opus/Local問わず)の表示には影響しないことを確認する
4. ダークモード両テーマでの表示を確認する
5. `docker compose up -d --build`で反映し、実画面(該当する旧履歴の表示)を確認する

## 完了報告

verified-report形式で簡潔に報告すること。修正前後の表示の違い、既存の正常な記録(model明記済み)への影響がないことの確認、`docker compose up -d --build`後の反映確認結果を含めること。

git操作は行わないこと。

---
**推奨モデル: Sonnet**(表示ロジックの条件分岐修正のみで、判断を伴わない機械的な実装のため)
