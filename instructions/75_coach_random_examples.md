# 75: 壁打ちの例文をプール(20〜30個)からランダムに3つ抽出する

## 背景

- 現在、Coachの壁打ち開始画面には固定の3つの例文(「rogue APのアラートが出てるんですが、何から見ればいいですか」「スイッチが落ちたって連絡が来たとき、最初に何を確かめますか」「WPA2とWPA3が混ざってると何がまずいんですか」)が表示されている
- これを、20〜30個程度の例文プールを用意し、画面表示のたびにその中からランダムに3つ抽出して表示する形に変更したい

## タスク

### Task 1: 例文プールの作成

1. 現状のCoachの実装コード(`plugins/coach/`)を確認し、現在の3つの例文がどこに定義されているか特定する
2. 20〜30個程度の例文プールを作成する。既存の3つ(rogue AP・スイッチダウン・WPA2/WPA3混在)を含めつつ、Coachの想定利用範囲(自社のナレッジ・調査履歴・ベストプラクティスでカバーされる話題)に沿って、無線・有線・セキュリティ・パフォーマンス等、幅広いジャンルから作成する
3. 既存のナレッジ・ベストプラクティスのルール一覧(Best Practiceタブの29 ID等)を参考に、実際にCoachが答えられそうな(材料が存在しそうな)話題を選ぶとよい
4. 例文プールは日英両方用意する(既存のi18n運用に合わせる)

### Task 2: ランダム抽出の実装

1. 壁打ち開始画面が表示されるたびに、例文プールから3つをランダムに抽出して表示するようにする
2. 同じ3つが連続で出やすい・偏りが大きい、といった単純な実装上の癖が無いか確認する(必要に応じて簡単な工夫をする程度でよい、厳密なシャッフルアルゴリズムまでは不要)

### Task 3: 動作確認

1. 壁打ち開始画面を複数回リロードし、表示される3つの例文が毎回変わることを確認する
2. 例文をクリックした際、これまで通り正しくその内容で壁打ちが開始されることを確認する
3. 日英切替でも例文プールの日英対応が正しく機能することを確認する
4. 実装完了後、本番Dockerコンテナのrebuildまで行い、本番ポート(8092)での動作確認まで実施する(標準運用ルール通り)

## 制約

- Central/Mistの設定変更は一切行わない
- git操作は行わない(コミット等は別途指示があるまで実施しない)
- 既存のCoach機能(hintLevel管理・ライブMCP・履歴閲覧等)を壊さないこと

## 完了報告

verified-report形式で報告すること。特に:

- 作成した例文プールの内容(一覧)
- ランダム抽出の実装内容
- 複数回リロードでの動作確認結果
- 本番反映の結果
