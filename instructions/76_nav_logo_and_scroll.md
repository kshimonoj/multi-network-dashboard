# 76: ナビゲーションバーの改善(ロゴ短縮 + タブバー横スクロール対応)

## 背景・問題

- 「ネットワーク調査」タブを選択している時だけ、ヘッダーのタブ一覧が2行になってしまう(選択中タブに付く枠線で幅が広がるため)
- 現在タブは10個(Global Overview, Event/Alert, Webhookログ, Streaming(Central), レポート, ナレッジ, ネットワーク調査, ベストプラクティス, タグ付き対象, Coach)+モデル表示+言語切替+ダークモード切替があり、今後もタブが増える見込み
- 左上の「Multi Network Dashboard」という表記が長く、タブバーの横幅を圧迫している

## 対応方針(確定)

1. 左上の「Multi Network Dashboard」表記を、ロゴまたは短い表記(例: 「MND」)に短縮する
2. タブ数が今後も増える可能性を踏まえ、タブバー自体を「増えても折り返さない」構造にする。**グルーピングやオーバーフローメニューではなく、横スクロール**で対応する(タブが画面幅に収まらない場合、タブ一覧のエリアだけ横スクロールできるようにする)

## タスク

### Task 1: ロゴ/短縮表記への変更

1. 現在の「Multi Network Dashboard」表記の実装箇所(`src/main.tsx`または`src/shell.tsx`等)を確認する
2. ロゴ(SVGアイコン等の簡単なもの)または短縮表記(例: 「MND」)に変更する。既存のfaviconがあれば、そのモチーフを流用してもよい。無理に凝ったデザインを作る必要はなく、まずは短くすることを優先する
3. 短縮後も、それが何のアプリかは一目で分かる程度の視認性を保つ(ツールチップやhover時の正式名称表示を添えてもよい)

### Task 2: タブバーの横スクロール対応

1. タブ一覧のコンテナに`overflow-x: auto`(または相当のCSS)を適用し、画面幅に収まらない場合は折り返さず横スクロールできるようにする
2. 選択中のタブが画面外にある場合、そのタブが見える位置まで自動でスクロールする配慮があるとなお良い(必須ではない)
3. モデル表示・言語切替・ダークモード切替は、タブの横スクロール対象に含めず、右端に固定表示のまま維持する(タブ一覧の横スクロールとは独立させる)
4. スクロールバーの見た目(細いスクロールバー、または横スクロール可能であることを示す軽い視覚的ヒント)を検討する。既存のデザイントークンに合わせる

### Task 3: 動作確認

1. 「ネットワーク調査」タブを選択した状態で、タブ一覧が2行にならず横スクロール(または収まる)することを確認する
2. 意図的にタブを増やした状態(テスト的に仮のタブを追加する、またはブラウザ幅を狭める)で、横スクロールが正しく機能することを確認する
3. ロゴ/短縮表記が正しく表示され、クリック等の既存の挙動(あれば)が壊れていないことを確認する
4. 日英切替・ダーク/ライトモードでの表示崩れが無いことを確認する
5. 既存の全タブ(Global Overview〜Coach)を一通り開き、ナビゲーション自体に問題が無いことを確認する
6. 実装完了後、本番Dockerコンテナのrebuildまで行い、本番ポート(8092)での動作確認まで実施する(標準運用ルール通り)

## 制約

- Central/Mistの設定変更は一切行わない
- git操作は行わない(コミット等は別途指示があるまで実施しない)
- 既存機能・既存タブの動作を壊さないこと
