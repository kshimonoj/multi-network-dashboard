# 04b: rechartsアニメーションの無効化(印刷/共有時のSVG複製リスク対策)

## 背景

03b/04で、印刷/共有機能は画面上に既にレンダリング済みのSVGをそのままクローンする方式を採っている。recharts(棒グラフ・折れ線グラフ)は初期表示時・再マウント時にデフォルトでアニメーションが有効になっており、その途中(0.4〜1.5秒、非表示タブでは無期限に停止)で複製が行われると、不完全な状態のグラフが静止画として固定されてしまう。

費用対効果として、アニメーション完了を待つような複雑な仕組みは導入せず、**アニメーション自体を全面的に無効化する**方針とする。これによりグラフは常に完成形で即座に表示されるようになる(通常の画面表示への影響も許容する)。

## タスク

1. `Chart.tsx`内でrechartsの各グラフコンポーネント(棒グラフ・折れ線グラフ・円グラフ等、アニメーション対象になり得る全ての種類)に`isAnimationActive={false}`を設定する
2. 設定漏れがないか、`Chart.tsx`内の該当コンポーネントを全件確認する
3. 通常の画面表示で、グラフが即座に完成形で表示されることを確認する(アニメーションで伸びる演出が完全になくなっていることを目視確認)
4. 03b/04で確認済みだった印刷/共有機能(単発・セッション全体とも)が引き続き問題なく動作することを確認する(退行がないことの確認)
5. `docker compose up -d --build`で反映し、`/health`と実画面を確認する

## 完了報告

verified-report形式で報告すること。特に:

- `isAnimationActive={false}`を設定したコンポーネントの一覧(設定漏れがないか)
- アニメーション無効化後の見た目の確認結果
- 印刷/共有機能に退行がないことの確認結果
- `docker compose up -d --build`後の反映確認結果

git操作は行わないこと。
