# 32: Streaming(Central)タブの辞書化

## 前提

29〜31番で確立したパターン(`src/i18n/ja.json`/`en.json`への名前空間追加 + `t()`経由の表示)を踏襲する。このタブは静的ラベル209件(UI文言188+srv→UI 21)と対象規模が大きいので、時間がかかるようであれば無理に1回で終わらせず、途中経過を`instructions/32_findings.md`に残しながら進めてよい。

## タスク

### Task 1: 対象範囲の再確認(前回の反省を踏まえる)

31番で、指示書が参照したレイアウト崩れ懸念箇所が実際には別タブのものだったという行き違いがあった。今回着手前に、Streaming(Central)タブの実装ファイル(`plugins/central-streaming/view/`配下等)を`grep`等で確認し、28番findingsに記載された209件が本当にこのタブのファイルに存在するかを確認してから着手すること。

### Task 2: Streaming(Central)タブの辞書化

1. `central-streaming.*`(または同様の)名前空間を`ja.json`/`en.json`に追加し、該当コンポーネントを`t()`経由の表示に置き換える
2. 対象に含めるべき主要な要素:
   - 接続状態表示(未接続/接続中/再接続中/エラー)
   - 有効/無効の手動トグル
   - 購読イベント種別選択(AP Monitoring/Audit Trail/Geofence/Location/Location Analytics、Audit Trailのサブタイプ)
   - Retention設定(保持期間・最大件数)のUI
   - イベント一覧表示(受信時刻・イベント種別・内容の要約等)
   - 「調査する」ボタン(既存のpendingInvestigationQuery経由の連携、getLang()連動も他タブと同様に対応する)
3. srv→UI文言(21件)は、30・31番と同じ判断基準(バックグラウンドで生成され特定閲覧者の言語コンテキストを持たない文言は現状維持でよい)で対応し、対応有無とその理由を記録する
4. protobufデコード結果のフィールド名(x/y座標、RSSI値等、実データそのものの項目名)は翻訳対象外とする(これはデータであり、UI文言ではないため)

### Task 3: レイアウト崩れの確認

1. 実際にStreaming(Central)タブのコンポーネントを確認し、英語表示で崩れそうな箇所(接続状態バッジ、購読イベント選択のチェックボックス群、Retention設定のプルダウン等)があれば、英語表示で実際に確認し対応する

### Task 4: 動作確認

1. Streaming(Central)タブで日英切替を行い、全要素が正しく切り替わることを確認する
2. 接続の有効/無効切替、購読イベント選択、Retention設定が英語表示でも問題なく機能することを確認する
3. 「調査する」ボタンで英語クエリが正しく生成されネットワーク調査タブに連携されることを確認する
4. 既存の辞書化済みタブ(共有/シェル・Global Overview・Event/Alert・Webhookログ)、未着手のネットワーク調査タブへの影響が無いことを確認する
5. ダークモード両テーマでの表示を確認する
6. `docker compose up -d --build`で反映し、実画面を確認する
