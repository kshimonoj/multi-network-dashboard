# 40: 39番デモ動画に「回答内容・粒度の違い」の訴求を追加(再録画が必要な場合は着手前に報告)

## 背景

39番の動画(`demo/demo_03_model_comparison.mp4`)は所要時間の差を見せる内容になっているが、それだけでなく**Sonnet/Localの回答内容そのものの違い**(特に2ターン目の回答の粒度・具体性、「続けて調べる」の実現方法の違い)も伝わるようにしたい。

**再録画が必要かどうかをまず判断し、必要な場合は着手前(字幕変更やffmpeg再生成に進む前)に一度報告し、ユーザーの指示を待つこと。独断で再録画を実行しない。**

## タスク

### Task 1: 再録画の要否判断

1. `demo/`配下に、39番の生録画データ・中間ファイル(37・38番と同様の構成のはず)が残っているか確認する
2. 残っており、かつ**既存の録画フレームの中に、Sonnet/Localそれぞれの2ターン目の回答画面が十分な解像度・表示時間で写っている**のであれば、再録画は不要と判断し、Task 2以降(字幕・キャプションの追加/再生成)に進んでよい
3. 既存フレームでは回答内容が読み取れない(画面が小さすぎる、スクロール位置的に回答本文が写っていない等)場合は、**再録画が必要と判断し、ここで作業を止めて完了報告で状況を説明し、ユーザーの指示を待つこと**

### Task 2: 実際の回答内容の比較分析(Task 1で再録画不要と判断できた場合のみ)

1. `data/network-investigation/query-history.jsonl`から、39番録画時のSonnet・Localそれぞれの2ターン目(「続けて調べる」相当)の回答本文を取得する
2. 以下の観点で、**実際のテキストを比較した上で、正直な所見**をまとめる(誇張や創作をしないこと。もし両者の粒度に有意な差が無ければ「差は小さかった」とそのまま記録すること):
   - 回答の文字数・構造(見出し/箇条書きの有無等)
   - 具体的な数値・デバイス名・サイト名等、固有情報の言及量
   - 「続けて調べる」の実現方法の違い(Sonnetは自動生成されたサジェストチップをクリック、Localはチップが生成されずチェックボックス+同一クエリ文での代替、という39番のDECISIONに記録された違い)
3. 分析結果を`instructions/40_findings.md`に記録する

### Task 3: 字幕・キャプションの追加(です・ます調)

1. Task 2の分析結果をもとに、実際の差異を正直に伝える字幕・キャプションを追加または既存字幕に追記する。例(あくまで実際の分析結果に応じて文言は調整すること):
   - 「Sonnetは追加のサジェスト質問を自動で提案します」
   - 「Localではサジェストが生成されず、同じ質問を手動で続けました」
   - 「2ターン目の回答を比べると、Sonnetは〜(実際の所見)、Localは〜(実際の所見)という違いが見られます」
2. 誇張表現(「圧倒的に」「はるかに」等)は避け、観察された事実に即した表現にすること
3. 必要であれば、両モデルの2ターン目の回答を並べて比較できる静止画面(テキストオーバーレイやピクチャーインピクチャー的な構成)を追加してもよいが、無理に凝った編集をする必要はない。既存フレームへの字幕追加で十分に伝わるならそれでよい

### Task 4: 再生成・保存

1. 修正した字幕・キャプションでffmpeg処理を再実行し、動画を再生成する
2. 既存の`demo_03_model_comparison.mp4`は上書きせず、別バージョンのファイル名(例: `demo_03_model_comparison_v2.mp4`)で保存する
3. 生成された動画から、回答内容の違いを訴求する場面のフレームを抽出し、字幕・テキストが正しく表示されていることを確認する
4. 既存の他の動画ファイルに影響が無いことを確認する
