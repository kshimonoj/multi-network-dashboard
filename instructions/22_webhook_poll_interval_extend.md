# 22: Webhookログのポーリング間隔選択肢に1時間・24時間を追加(multi-network-dashboard)

## タスク

1. Webhookログタブのポーリング間隔設定(現状の選択肢・上限クランプ値)を確認する
2. 選択肢に**1時間**・**24時間**を追加する
3. サーバー側のクランプ上限(現状30分が上限になっている場合はそれ)を、24時間まで許容するよう引き上げる。下限は既存のまま(60秒等)で変更しない
4. 選択肢の表示ラベルを分かりやすく整える(例: 1分/3分/5分/10分/15分/30分/1時間/24時間)
5. 実際に1時間・24時間を選択し、設定が保存・反映され、コンテナ再作成後も保持されることを確認する
6. Global Overview側のポーリング間隔設定には影響しないことを確認する(独立した設定のため)
7. `docker compose up -d --build`で反映し、実画面を確認する

## 完了報告

verified-report形式で簡潔に報告すること。追加した選択肢、クランプ上限の変更内容、実際の動作確認結果(設定保存・再作成後の保持)、Global Overview側への影響がないことの確認、`docker compose up -d --build`後の反映確認結果を含めること。

git操作は行わないこと。
