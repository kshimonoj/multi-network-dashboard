# 14: Event/Alertの取得方式をUI上に明示する(multi-network-dashboard)

## 方針(確定)

Event/Alertタブの取得方式(Global Overviewの自動ポーリングとは別で、タブを開いた時・「更新」ボタン押下時のみ取得、60秒キャッシュ)は変更しない。Global Overviewの自動ポーリング(既定5分・設定変更可能)とは仕組みが異なることを、画面上で誤解なく分かるように明示する。

## タスク

1. Event/Alertタブの画面内(既存のGlobal Overviewのフッターにある「ポーリング間隔」表示と対になる位置)に、以下が伝わる表示を追加する:
   - このタブは自動更新されないこと
   - データはタブを開いた時・「更新」ボタン押下時に取得され、60秒間キャッシュされること
   - 最終取得時刻(既にあれば流用、なければ追加する)
2. Global Overview側のポーリング間隔設定UI(プルダウン)の近くにも、「この設定はGlobal Overviewの自動更新にのみ適用され、Event/Alertタブには適用されない」旨の注記を追加する
3. 表現は簡潔にし、UIが煩雑にならないようにする(長い説明文ではなく、小さな注記やツールチップ程度でよい)
4. ダークモード両テーマでの表示を確認する
5. `docker compose up -d --build`で反映し、実画面を確認する

## 完了報告

verified-report形式で簡潔に報告すること。Event/Alertタブおよびポーリング間隔設定UI周りの表示内容(実際の文言)と、`docker compose up -d --build`後の反映確認結果を含めること。

git操作は行わないこと。
