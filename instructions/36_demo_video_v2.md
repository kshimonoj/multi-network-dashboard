# 36: デモ動画の再撮影(Event/Alertの「調査する」→ネットワーク調査→ワンクリック「続けて調べる」)

## 背景

35番で同テーマの動画を作成済みだが、以下4点を反映して撮り直す。34番・35番と同じ録画環境(Playwright + ffmpeg)をそのまま使う。

## 反映する修正点

1. **Event/Alertの選定**: 一覧の中から、**authentication系**のイベント/アラート(認証失敗、RADIUS関連、802.1X関連など、「authentication」というカテゴリ・キーワードに該当するもの)を選んで「調査する」を押すこと。適当な行ではなく、実際に画面のフィルタや一覧を確認し、authentication系の項目を探して選ぶこと。存在しない場合は、テストデータ側にauthentication系のイベントが無いことを報告し、代わりに何を選んだかを明記すること(推測でそれらしい行を選ばない)
2. **「続けて調べる」の操作**: 前回(35番)は「スレッドの続きとして実行する」相当の操作(チェックボックス+新規クエリ入力)を想定していたが、そうではなく、**回答表示後にある「続けて調べる」のワンクリック操作(ボタンやサジェストされた追加質問チップ等、1クリックで完結するもの)を実際にクリックして続けて調べること**。まず画面を確認し、「続けて調べる」に相当するUI要素が具体的に何であるか(ボタンのラベル、位置、チェックボックスではなくワンクリックであること)を特定してから撮影に進むこと。チェックボックスをオンにして別途クエリを入力する操作は行わない
3. **字幕の文体**: 日本語字幕はすべて**です・ます調**で記載すること(例: 「発生したイベントから直接『調査する』を押します」のような文体。体言止めや常体は使わない)
4. **早送り**: 調査実行中(MCP呼び出し・SSEログ表示・回答生成待ち)の時間が長く単調になる区間があれば、動画編集(ffmpegの`setpts`フィルタ等)で早送りにすること。実装が難しい・時間がかかる場合は、早送りを省略し、その旨とスキップした理由を完了報告に明記してよい(オプション対応)

## タスク

### Task 1: シナリオの確認と実行

1. Event/AlertタブでauthenticationカテゴリのEvent/Alertを実際に探し、該当する行を確認する(前述の1)
2. その行の「調査する」を押し、ネットワーク調査タブへの自動遷移(クエリ・サイトの事前入力)を確認する
3. そのまま「実行」し、SSEでのMCP呼び出しログ表示・最終回答表示までを撮影する
4. 回答表示後、「続けて調べる」のワンクリック操作を実際に特定し、それをクリックして追加の関連質問を実行する(前述の2)
5. 2ターン分の調査が1つのセッションスレッドとしてまとまって表示される様子を撮影する

### Task 2: 字幕の焼き込み

各場面に合わせて日本語字幕(です・ます調)を焼き込む。例(文体の参考。実際の画面の流れに合わせて調整してよい):

- 「① Event/Alertタブで、認証関連のイベントから『調査する』を押します」
- 「② ネットワーク調査タブに自動で切り替わり、クエリとサイトが入力されます」
- 「③ MCP経由でAIが調査を実行します」
- 「④ 『続けて調べる』をクリックし、同じスレッドで深掘りします」
- 「⑤ 一連の調査が1つのセッションとして記録されます」

### Task 3: 早送り編集(可能なら)

1. 録画から、調査実行中で画面がほぼ変化しない区間(SSEログが少しずつ流れる程度の待ち時間)を特定する
2. 該当区間を2〜4倍速程度に早送りする(音声は無いため速度変更のみでよい)
3. 難しい場合は省略し、理由を報告する

### Task 4: 出力・確認

1. `.webm`を`.mp4`に変換する
2. `demo/`ディレクトリに、35番の動画と区別できるファイル名で保存する(例: `demo_02b_event_to_investigation_v2.mp4`)
3. 完成した動画のファイル名・パス・再生時間・ファイルサイズを確認する

## 完了報告

verified-report形式で報告すること。特に:

- authentication系イベントとして実際に選んだ行の内容(見つからなかった場合はその旨と代替対応)
- 「続けて調べる」に相当する実際のUI要素が何だったか(ボタンかチップか、ラベル文言)
- 字幕の文体がです・ます調で統一されていることの確認
- 早送り編集の実施有無(実施した場合は対象区間・倍率、省略した場合はその理由)
- 動画の保存先パス・再生時間・ファイルサイズ
- 今回のスコープ外(他タブ)への影響が無いこと

git操作は行わないこと。
