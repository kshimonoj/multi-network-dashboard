# 34: デモ動画作成(Global Overview → Event/Alert → ネットワーク調査、字幕付き)

## 目的

multi-network-dashboardの動作デモ動画を作成する。今回はGlobal Overview・Event/Alert・ネットワーク調査(クエリ実行)の3タブに絞った短いデモとする。ナレーションは不要、場面ごとの日本語字幕(焼き込みテキスト)は入れる。将来的に全タブへ拡張する前提の試作として進める。

## タスク

### Task 1: 録画環境の準備

1. Playwrightがプロジェクトに導入されていなければ、devDependencyとして追加する(`@playwright/test`または`playwright`)。既存の本番依存関係には影響を与えないこと
2. Playwrightの録画機能(`recordVideo`オプション)を使って、ブラウザ操作の様子を`.webm`として保存できることを確認する
3. `ffmpeg`がホスト(Mac)に無ければ、`brew install ffmpeg`でインストールする

### Task 2: デモシナリオの作成・実行

以下の流れを1本の録画にまとめる台本を作成し、Playwrightスクリプトとして実装・実行する。各場面の目安の秒数・字幕文言も設計してよい(自然な間を持たせること):

1. **Global Overview**: タブを開き、Global Summary(サイト数・デバイス数・クライアント数・アラート数)、プラットフォーム別ドーナツチャート、地図、サイト別内訳テーブルが見える程度にスクロール・少し待機する
2. **Event/Alert**: タブに切り替え、イベント一覧・フィルタ操作(例: 重要度で絞り込む)を軽く行う
3. **ネットワーク調査**: タブに切り替え、適当な質問(例:「全体の健全性状況を教えて」)を入力して実行し、SSEでのMCP呼び出しログのリアルタイム表示・最終的な回答が表示されるまでを見せる

録画は日本語UI・ライトまたはダークいずれか見栄えの良い方(判断してよい)で行う。

### Task 3: 字幕の焼き込み

1. 各場面の開始・終了タイミングに合わせて、`ffmpeg`の`drawtext`フィルタ(またはSRT字幕ファイル+`subtitles`フィルタ)で、画面下部に短い日本語の説明テキストを焼き込む。例:
   - 「① Global Overview — Central/Mistの状況をひと目で確認」
   - 「② Event / Alert — 発生したイベント・アラートを一覧・絞り込み」
   - 「③ ネットワーク調査 — 自然文で質問し、MCP経由でAIが調査」
2. 字幕は画面の主要な操作対象を隠さない位置(下部)に、読める程度の時間(2〜4秒程度)表示する

### Task 4: 出力・確認

1. `.webm`を`.mp4`(H.264等、一般的なプレイヤーで再生可能な形式)に変換する
2. 完成した動画のファイルサイズ・再生時間を確認し、`/Users/kshimono/claude/multi-network-dashboard/demo/`(無ければ新規作成)等の分かりやすい場所に保存する
3. 動画ファイルのパスを完了報告に明記する

## 完了報告

verified-report形式で報告すること。特に:

- 録画・変換に使ったツール構成(Playwrightのバージョン、ffmpegの有無)
- 実際にできた動画の長さ・ファイルサイズ・保存先パス
- 字幕が意図通りのタイミングで表示されていることの確認方法(目視確認したか等)
- 今回のスコープ外(他タブ)への影響が無いこと(devDependency追加のみで本番ビルドに影響しないことの確認)

git操作は行わないこと。
